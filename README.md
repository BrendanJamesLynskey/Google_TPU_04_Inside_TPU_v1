# Inside TPU v1 &mdash; The 2015 Inference Chip

A slide-by-slide opening of TPU v1 &mdash; the 28&nbsp;nm 256&times;256 INT8 systolic MMU, 24 MiB Unified Buffer, 4 MiB accumulators, the brilliantly minimal ~12-instruction CISC ISA, why it shipped with DDR3 instead of HBM, the roofline that explains why v1 was memory-bound, and what v1 got right (and wrong) for every TPU since. Block diagram + roofline visualisations.
